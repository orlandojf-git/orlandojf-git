## SIEM Security Monitoring Lab

**Status:** 🟡 In Progress

I am currently developing a Security Information and Event Management (SIEM) lab to gain hands-on experience with security monitoring, log analysis, detection engineering, and incident investigation.

The goal of the lab is to simulate aspects of a real-world security operations environment where security events are collected, analyzed, investigated, and escalated.

### Objectives

- Deploy and configure a SIEM environment
- Collect and centralize security logs
- Generate simulated security events
- Develop detection rules
- Investigate suspicious activity
- Analyze authentication and system activity
- Create security alerts
- Document incident investigations
- Develop an understanding of SOC workflows

### Technologies

- Splunk
- Linux
- Windows
- AWS
- Networking
- SIEM / Log Analysis
- Security Monitoring

### Planned Investigations

As the lab develops, I plan to investigate scenarios such as:

- Brute-force authentication attempts
- Suspicious PowerShell activity
- Privilege escalation
- Unauthorized access
- Malicious network activity
- Account compromise
- Data exfiltration indicators

The completed project will include architecture documentation, detection logic, investigation notes, screenshots, and incident reports.
